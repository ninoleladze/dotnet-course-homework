# .NET Course Homework

My coursework and practice projects from learning **C#, .NET, ASP.NET Core, Entity Framework Core, SQL and Angular** — 189 exercises in one place.

Bigger projects live in their own repositories (see my profile). This repository collects the lessons, homework and practice tasks.

## What's inside

- **C# fundamentals** — variables, conditions, loops, methods, OOP, collections, LINQ
- **Advanced C#** — generics, reflection, attributes and validation, async/await and TPL, thread pool, JSON and XML serialization
- **Dependency injection** — the `*_DI` folders are DI lessons (service lifetimes, interfaces, notifiers)
- **Entity Framework Core** — code-first models, relationships, migrations, CRUD services
- **ASP.NET Core** — Web APIs, routing, middleware, DI, authentication with JWT
- **SQL** — select, joins, grouping, aggregation, subqueries, ALTER TABLE, data insert
- **Testing** — unit tests and mocking
- **Frontend** — first Angular and React projects
- **Python** — first Python practice (in `desktop-python`)

## Running a project

Every folder is a standalone project. Open the `.sln`/`.slnx` in Visual Studio or run from the folder:

```bash
cd <folder>
dotnet run        # or: dotnet test
```

For Angular / React folders: `npm install` then `npm start`.
